# 3D Vision: Wide-Baseline Pose Estimation and Sparse-View 3D Gaussian Splatting

Course project for NTU Deep Learning for Computer Vision (Fall 2025), HW4. The full report is in `hw4_b11103049.pdf`.

## Part 1: DUSt3R pose estimation on wide-baseline pairs

DUSt3R predicts dense 3D point maps from image pairs and recovers camera poses through global alignment. It works well on ordinary pairs but struggles when the two views are far apart (wide baseline).

Following the InterPose idea, this part compares DUSt3R on:
- the original wide-baseline image pairs, and
- sequences that add in-between frames generated by a video model (frames provided with the assignment).

**What I did**
- Wrote the DUSt3R inference and evaluation pipeline (`dust3r_inference.py`) for both settings.
- Evaluated relative rotation error. With generated in-between frames, the mean rotation error dropped from **84.8° to 75.4°**, and accuracy under 30° rose from **25.0% to 42.5%**.
- Analyzed failure cases where the PnP solver breaks on degenerate (co-planar or co-linear) points, and added error handling for these cases.

## Part 2: Sparse-view 3D Gaussian Splatting

Reconstructs a scene from a few posed images with [InstantSplat](https://github.com/NVlabs/InstantSplat) and renders novel views from unseen test cameras.

**What I did**
- Built the train and render pipeline (`hw4_2.sh`) on top of InstantSplat.
- Compared three settings of training iterations and image resolution. The best setting reached about **PSNR 18, SSIM 0.56, LPIPS 0.38** (from PSNR 11, SSIM 0.45, LPIPS 0.55 in the weakest setting).
- Compared 3D Gaussian Splatting with NeRF-based representations in the report.
